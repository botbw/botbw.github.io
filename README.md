# botbw.github.io

Personal academic homepage of Haoxuan Wang, live at <https://botbw.github.io>.

Built with Jekyll from the [academic-homepage](https://github.com/luost26/academic-homepage) template (MIT License, see `LICENSE`).

## Editing

- Profile, bio, education, experience, awards: `_data/profile.yml`
- Publications: `_publications/<year>/*.md`
- Navigation: `_data/navigation.yml`

## Local preview

```bash
bundle config set --local path vendor/bundle
bundle install
bundle exec jekyll serve
```
